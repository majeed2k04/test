``` ### 🔴 One important change in your existing login page Your login page must save the username when the user successfully logs in. Inside your existing login JavaScript, after successful login, add: ```javascript localStorage.setItem("username", username); window.location.href = "index.html"; ``` For example, if your login code has: ```javascript if (username === "admin" && password === "1234") { ``` change it to: ```javascript if (username === "admin" && password === "1234") { localStorage.setItem("username", username); window.location.href = "index.html"; } ``` ### What will happen Suppose the user logs in as: ```text Username: abdul Password: ******** ``` Then they search: ```text how to learn cybersecurity ``` The website sends this to your Formspree form: ```text username: abdul search_query: how to learn cybersecurity ``` Then the browser opens: ```text Google → how to learn cybersecurity ``` So in Formspree you can see **who searched and what they searched**. ### GitHub steps In your existing repository: **1.** Open your GitHub repository. **2.** Open your current `index.html`. **3.** Click **Edit** ✏️. **4.** Replace the existing code with the code above. **5.** Click **Commit changes**. **6.** Make sure your login page stores the username using: ```javascript localStorage.setItem("username", username); ``` **7.** Open your GitHub Pages website. **8.** Login → enter a search → click **Search**. **9.** Check your Formspree dashboard. You should receive the submitted username and search query. **Important:** This approach identifies users only by the username your site stores in the browser. It does **not** securely authenticate users, and you should not use it to collect passwords or other sensitive information.
